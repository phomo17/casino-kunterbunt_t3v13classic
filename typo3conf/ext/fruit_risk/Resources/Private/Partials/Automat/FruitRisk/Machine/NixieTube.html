Eine Nixie-Röhre dieses Geraets. Zylindrischer Glaskolben, davor ein Drahtgitter als Anode, dahinter ein Stapel geformter Drahtkathoden — eine je Ziffer 0 bis 9, hintereinander in unterschiedlicher Tiefe. Die belegte Reihenfolge von vorn nach hinten ist 6 7 5 8 4 3 9 2 0 1, so gewaehlt, dass unbeleuchtete Ziffern die leuchtende moeglichst wenig verdecken. Im Markup stehen sie deshalb RUECKWAERTS: das zuletzt geschriebene Element wird zuletzt gemalt und liegt damit vorn. --fr-depth ist der Platz im Stapel (0 = vorderste Kathode) und steuert Deckkraft und Versatz der Drahtkontur. Welche Kathode brennt, entscheidet --fr-digit auf dieser Roehre, rein rechnerisch in CSS — siehe machine.css, Abschnitt 4. -1 bedeutet: keine. Phase F4 aendert die Zahl mit roehre.style.setProperty('--fr-digit', 7); ohne eine einzige Zeile Markup anzufassen. --fr-tube ist nur die laufende Nummer der Roehre in ihrer Gruppe. Sie versetzt das Flimmern, damit nicht alle Roehren im Gleichschritt zucken.
