Eine Nixie-Röhre. Aufbau nach DESIGNBRIEF.md Abschnitt 5: zylindrischer Glaskolben, davor ein Drahtgitter als Anode, dahinter ein Stapel geformter Drahtkathoden — eine je Ziffer 0 bis 9, hintereinander in unterschiedlicher Tiefe. Die belegte Reihenfolge von vorn nach hinten ist 6 7 5 8 4 3 9 2 0 1, so gewählt, dass unbeleuchtete Ziffern die leuchtende möglichst wenig verdecken. Im Markup stehen sie deshalb RÜCKWÄRTS: das zuletzt geschriebene Element wird zuletzt gemalt und liegt damit vorn. --cp-depth ist der Platz im Stapel (0 = vorderste Kathode) und steuert Deckkraft und Versatz der Drahtkontur. Welche Kathode brennt, entscheidet --cp-digit auf dieser Röhre, rein rechnerisch in CSS — siehe machine.css, Abschnitt 4. -1 bedeutet: keine. Lauf 2 ändert die Zahl mit roehre.style.setProperty('--cp-digit', 7); ohne eine einzige Zeile Markup anzufassen. --cp-tube ist nur die laufende Nummer der Röhre in ihrer Gruppe. Sie versetzt das Flimmern, damit nicht alle Röhren im Gleichschritt zucken.
